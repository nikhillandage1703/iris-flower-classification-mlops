💡 Technical Analysis & Viva Explanation

Why Random Forest vs Decision Tree?

Decision Tree Classifier: A non-parametric supervised learning algorithm that partitions the feature space using recursive binary splits guided by Gini impurity. While highly interpretable, standalone decision trees are prone to high variance and overfitting.


Random Forest Classifier: An ensemble bagging algorithm that aggregates 100 decorrelated decision trees trained on bootstrap samples with random feature subsets. By averaging individual tree predictions, it drastically mitigates variance, stabilizes boundaries, and delivers superior generalization on unseen flowers.

📐 Multiclass Averaging Methodology

Macro Averaging vs Weighted Averaging

Weighted Averaging: Calculates performance metrics for each target class individually, and computes their average weighted by the support (number of true instances) of each class. This is vital when handling imbalanced real-world datasets.

Macro Averaging: Calculates the metric for each class independently and calculates their unweighted arithmetic mean, assigning equal importance to every class regardless of class prevalence.

Application Note: Because our stratified test split preserves exactly 10 instances for Setosa, 10 for Versicolor, and 10 for Virginica, macro and weighted averages produce consistent and mathematically aligned results.

🔄 End-to-End MLOps Architecture

Complete lifecycle from raw data ingestion to production API and CI/CD automation

1

Dataset Ingestion & Standardization

Loads 150 instances from Scikit-Learn, standardizes feature schema names, validates 0 missing entries, and writes raw dataset to data/raw/iris.csv.

src/data/load_data.py
2

Data Validation & Schema Integrity

Strictly tests shape dimensions, numerical boundaries, non-zero physical measurements, and 50-per-class balance prior to pipeline execution.

src/data/validate_data.py
3

Data Version Control (DVC) Tracking

Configured with dvc.yaml and params.yaml to orchestrate deterministic, reproducible stage executions with hash-based caching.

dvc repro • dvc.yaml
4

Data Preprocessing & Stratified Splitting

Separates features and targets, performs stratified 80-20 splitting (120 train / 30 test) with fixed random seed (42) to eliminate data leakage.

src/features/preprocess.py
5

Model Training & MLflow Experiment Tracking

Trains Decision Tree and Random Forest models. Logs hyperparameters, train/test metrics, confusion matrix artifacts, and serialized model flavors to MLflow experiment Iris_Classification_Experiment.

src/models/train.py • MLflow
6

Automated Best-Model Selection & Joblib Serialization

Compares test F1-scores, selects superior generalizer, serializes best_model.joblib, and exports model_metadata.json.

joblib • models/best_model.joblib
7

FastAPI RESTful Backend Serving

Exposes production endpoints (/health, /model-info, /predict, /predict-batch) with Pydantic validation and Swagger documentation at /docs.

src/api/app.py • Uvicorn
8

Continuous Integration / Continuous Deployment (CI/CD)

Automated GitHub Actions workflow (.github/workflows/ci-cd.yml) triggers on push/PR, installs environment, reproduces pipeline, and executes 21 Pytest checks.

pytest • GitHub Actions

Primary Objective: Design, build, version, test, containerize, and deploy an end-to-end Machine Learning Operations system for botanical species classification.

Key Engineering Principles: Zero data leakage, deterministic reproducibility via DVC, experiment governance via MLflow, automated unit/integration testing with Pytest, and RESTful service exposure.
